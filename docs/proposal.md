# Project proposal

**Title:** Development of a web-based platform for planning, monitoring and analysing open lessons of teaching staff
at a higher education institution

| | |
| --- | --- |
| Team | Dana Shokobalinova (PM, research, QA), Nurdaulet Saparbekov (backend and architecture), Amina Sergazina (frontend and UI / UX) |
| Supervisor | Yersultan Tulebayev |
| Client | Academic-Methodological Department, Astana IT University |

## Problem

Open lessons are planned, announced, checked and reported by hand. Nobody controls the deadline for slides and lesson
plans, feedback arrives late or gets lost, and trimester reports are built manually.

## Aim

Build OpenLesson, one web platform that automates planning, monitoring and analysis of open lessons, with AI-supported
feedback summaries.

## Objectives

1. Study the current process: the client and 3-4 interviews.
2. Review the literature and similar systems.
3. Specify requirements, design the system and the user interface.
4. Implement the 8 modules of the specification.
5. Pilot the platform for one trimester and evaluate it.

## Target users

- Administrator / methodologist
- Teacher giving the lesson
- Observing teacher
- Dean / deputy dean
- University leadership

## Expected outcomes

- A working prototype with 8 modules
- The automated 10 / 7 / 3-day lesson cycle
- All feedback and an AI summary in one teacher cabinet
- A dashboard, Excel and PDF reports, documentation

## Scope

**In:** 8 modules, 5 roles, responsive web interface, university e-mail, Excel import, AI as advice.

**Out:** a native mobile app, video of lessons, full HR or LMS integration, AI decisions without a human.
