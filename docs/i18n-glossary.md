# Глоссарий интерфейса OpenLesson · KK / RU / EN

Единая терминология для переводов интерфейса, писем, отчётов и постеров. Казахский текст
желательно вычитать носителю языка (кафедра казахского языка / коллеги) перед защитой.

Правила для казахского:
- обращение на «Сіз» (сізге, сіздің);
- после числительных существительное в единственном числе: «3 күн», «5 пікір», «2 оқытушы»;
- даты: «2026 жылғы 15 қазан», короткий формат — «15 қазан»; время 24-часовое;
- названия кнопок — инфинитив/повелительная форма: «Сақтау», «Жіберу», «Жүктеу»;
- «ЖИ» = жасанды интеллект (AI), «ПОҚ» = профессор-оқытушылар құрамы (ППС).
